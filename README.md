# Лист персонажа

Генератор листов персонажа для настольных ролевых игр. Go + html/template, без JS-фреймворков.

- Выбор шаблона редакции: D&D 5e (официальный русский лист) и Shadowdark.
- Заполнение руками, частичный рандом (кубик у каждого поля) или «Всё случайно».
- Характеристики бросаются по правилам редакции: 4к6 без худшего для 5e, 3к6 по порядку для Shadowdark. Кубики крутятся на экране (3D на CSS).
- Готовый лист ложится на печатный PDF-шаблон (`assets/sheets`), открывается, скачивается или сразу уходит на печать.
- Фоновая музыка: mp3 из папки `music/` (в репозиторий не входит, задаётся флагом `-music`), включается кнопкой в шапке.
- Мобильная вёрстка.

## Запуск

```bash
go run . -addr :8080
```

## Структура

- `internal/rules` — редакции: данные, генерация, подсчёт производных, раскладка полей на PDF.
- `internal/sheet` — обёртка над gopdf: подложка-шаблон, шрифты, текст в прямоугольниках.
- `internal/dice` — кубики.
- `web/templates`, `web/static` — страницы, стили, скрипты.
- `assets/sheets` — PDF-шаблоны (переписаны pdfcpu без object streams, иначе gopdf их не читает), `assets/fonts` — DejaVu с кириллицей.

Новая редакция = новый файл в `internal/rules`, реализующий `Edition`, плюс шаблон страницы `web/templates/sheet_<id>.html` и регистрация в `main.go`.

## Деплой

GitHub Actions (`.github/workflows/deploy.yml`): на push в main собирается статический бинарник linux/arm64 и по ssh передаётся на сервер, где `deploy/receive.sh` подменяет его и перезапускает systemd-сервис `deploy/char-list.service`. Наружу отдаёт Traefik (`deploy/traefik-char.yaml`). Секреты: `DEPLOY_HOST`, `DEPLOY_HOST_KEY`, `DEPLOY_KEY`.
